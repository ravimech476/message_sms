File Format

Your upload file must follow these formatting guidelines.

Column Reference

Column Name Description Required Example
phone Phone number in international format Required +447700900123
message SMS message text (overrides template) Optional Your order #123 is ready
name Recipient name for {name} merge Optional John Smith
custom1 Custom field for {custom1} merge Optional ORD-12345
custom2 Custom field for {custom2} merge Optional 10:30 AM
custom3 Custom field for {custom3} merge Optional Branch A
schedule Schedule time per row (YYYY-MM-DD HH:MM) Optional 2024-12-25 09:00

Sample CSV Structure

phone,name,message,custom1
+447700900123,John Smith,Hello {name}! Your order {custom1} is ready.,ORD-001
+447700900124,Jane Doe,Hello {name}! Your order {custom1} is ready.,ORD-002
+447700900125,Bob Wilson,Hello {name}! Your order {custom1} is ready.,ORD-003

Common Formatting Errors

Error Cause Solution
Invalid column header Column name doesn't match expected names Use exact column names: phone, message, name
Excel number format Numbers displayed in scientific notation Format cells as Text before entering numbers
Encoding issues Special characters appear corrupted Save file as UTF-8 encoded CSV
Empty rows Blank rows between data Remove all empty rows from file

Blacklist Management

View phone numbers that have opted out (sent STOP command).

Blacklist Page

Understanding Blacklist

The blacklist contains phone numbers that have requested to stop receiving messages. These are added automatically when recipients:

  • Reply with STOP to any message
  • Reply with UNSUBSCRIBE to opt out
  • Reply with CANCEL or QUIT
  • Are manually added by you

Blacklist Information

Field Description
Phone Number The opted-out phone number
Date Added When the number was blacklisted
Source How it was added (STOP reply, Manual, API)
Keyword The keyword they replied to (if applicable)

Managing Blacklist

Search

Find specific numbers in the blacklist

Manually add a number to blacklist

Remove a number (if requested)

Download full blacklist as CSV

Compliance Requirements

Requirement Description
Honor Opt-Outs Never send to blacklisted numbers
Process Within 24hrs Stop requests must be honored promptly
Include Opt-Out Info Marketing messages should include "Reply STOP to opt out"
Maintain Records Keep records of opt-outs for compliance

Re-subscribing

If a recipient wants to re-subscribe after opting out:

  • Recipient sends START or SUBSCRIBE to your number
  • You can manually remove them from the blacklist
  • They will then receive messages again
Important

Sending messages to opted-out numbers violates compliance regulations and may result in account suspension. Always respect opt-out requests.

Compliance

Blacklisted numbers are automatically excluded from all campaigns. You cannot accidentally send to these numbers through the platform.

Best Practice

Regularly export your blacklist for backup. Include clear opt-out instructions in your marketing messages to maintain trust with your recipients.

Sub-Accounts

A master account can create one or more sub-accounts — separate logins that sit under your account, each with its own username, password and wallet. This is useful for separating departments, clients or teams. You can move money to a sub-account at any time (see Transfer Money Between Accounts).

Master accounts only

Only a master account can create sub-accounts. If you are signed in to a sub-account, the “Add Sub-Account” button will not appear.

The Accounts page — master accounts see the “Add Sub-Account” button

How to Add a Sub-Account

  • Open the Accounts page from the Campaign Manager menu
  • Click Add Sub-Account (top right)
  • Fill in the new account’s details (see the table below)
  • Click Create Sub-Account
  • The system generates a username and password for the new sub-account — copy these and share them securely with the user

The “Add New Sub-Account” form

Sub-Account Fields

Field Description Required
Contact Name The name of the person who will use the sub-account. Required
Business Name The business or department name for the sub-account. Required
Email Address A valid email address for the sub-account holder. Required
Phone Number A contact telephone number. Required
Mobile Number A mobile number for the sub-account holder. Optional
After creating a sub-account

The new sub-account appears in your Accounts list beneath the master. Its wallet starts at £0.00 — use Transfer Money Between Accounts to top it up so it can send messages.

Transfer Money Between Accounts

If you manage a master account with one or more sub-accounts, you can move wallet funds (money) between them instantly — for example, topping up a sub-account from the master, or pulling unused balance back. This is done from the Accounts page in the Campaign Manager.

Accounts page — each account shows its current wallet balance

How to Transfer Funds

  • Open the Accounts page from the Campaign Manager menu
  • Scroll to the Transfer Wallet Funds Between Accounts panel
  • Choose the From Account — the account the money is taken from (its current balance is shown beside each name)
  • Choose the To Account — the account that will receive the money
  • Enter the Amount (£) you want to transfer
  • Click Transfer

The “Transfer Wallet Funds Between Accounts” panel

Transfer Fields

Field Description Required
From Account The account the funds are taken from. Must have enough balance to cover the amount. Required
To Account The account that receives the funds. Required
Amount (£) The amount to move, in pounds (e.g. 25.00). Must be greater than zero. Required
Instant & free

Transfers happen immediately — both balances update straight away and a confirmation message is shown. There is no charge for moving money between your own accounts.

Before you transfer

You can only transfer between accounts you manage (your master and its sub-accounts). The From account must have sufficient balance, and the From and To accounts must be different. Every transfer is logged for your records.
