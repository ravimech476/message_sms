Sales Report Tab

The Sales Report is the last tab on the Reports page. It lists every invoice for the chosen period, grouped by month, with revenue totals split by payment method. Use it to review monthly sales, outstanding (unpaid) invoices, and per-customer billing.

Running a Sales Report

  • Open Reports and click the Sales Report tab.
  • Pick a From (Month & Year) and To (Month & Year) using the month pickers.
  • Optionally tick Status filters — Paid, Not yet paid, Deleted (all are included if none are ticked).
  • Optionally tick Payment Method — PayPal / Card or BACS (all if none ticked).
  • Optionally choose one or more Customers (leave blank for all customers).
  • Click Show Report to preview on screen, or Generate Report to build an Excel file in the background.

Reading the Results

Each month appears as a collapsible card showing the invoice count and totals: Total, PayPal/Card, BACS, and Not yet paid. Expand a card to see every invoice with its Invoice #, date, customer, payment method, status badge, and amount (ex-VAT).

Open a customer straight from the invoice

In the preview, each Invoice # is a clickable link (shown in purple). Click it to open that customer's admin page in a new browser tab — handy for checking the account without losing your report.

Show Report vs Generate Report

Show Report previews the data instantly on screen. Generate Report builds a full Excel export in the background and emails you a download link when it is ready; the file also appears under Report History lower down the page. Use Generate for large date ranges so the page never times out.

Best Practice

Use "Manual" source for negotiated rates to prevent API overwrite. Export data before bulk changes.

Global Pricing

Global Pricing is its own menu in the left sidebar (under Cost Management). It is the single place to control two things: the default SMS rate a brand-new customer is created with, and the customer-facing prices shown on the Contracts page. Values are saved once and used everywhere, so there are no hard-coded prices to hunt down in code.

Global Pricing (Admin → Global Pricing)

Who can see it?

The menu and page are gated by the Global Pricing (Menu Access) permission. It is granted to all admins automatically, and can be turned on/off per admin from Admin Users → Edit → Menu Access Permissions. If an admin does not have the permission, the menu is hidden for them and the page cannot be opened.

New Customer Onboarding Rate

The default UK SMS rate applied to a new customer's routes when their account is created (Add Customer). It is also shown as a note on the Add Customer form and reflected on the customer's SMS Rates tab. This value must be at or above cost price — it exists to stop new accounts being created below cost.

Field Meaning Default
Onboarding SMS rate (£ per SMS) UK rate a new customer's account starts on £0.0457 (4.57 pence)

Contracts Pricing

These values are shown on the customer Contracts page for information only (customers cannot edit them). Editing here updates exactly what customers see on their contract.

Field Meaning Default
Effective from Date the contract pricing takes effect (shown on the Contracts page) 01/09/2025
Virtual UK number / keyword (£ per year) Annual price of a dedicated virtual number or keyword £250 / year
Overseas SMS (pence per text) Rate for international (non-UK) SMS 0.6 pence
UK Tier 1 — up to / rate UK monthly volume up to this many texts uses this rate up to 20,000 → £0.0457
UK Tier 2 — up to / rate UK monthly volume up to this many texts uses this rate up to 50,000 → £0.0390
Over Tier 2 — rate UK rate once monthly volume passes the Tier 2 threshold £0.0356

How to Edit

Step Action
1 Open Global Pricing from the left sidebar (under Cost Management).
2 Change any value in the New Customer Onboarding Rate or Contracts Pricing cards.
3 Click Save Pricing. A green confirmation appears and the new values are live immediately.
Where these values appear

The onboarding rate is used on Add Customer (and shown on the customer's SMS Rates tab); the Contracts Pricing values are shown on each customer's Contracts page. Changing a value here updates all of those places at once.
