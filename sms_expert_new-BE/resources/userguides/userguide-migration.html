Customer Migration Guide

Step-by-step guide to migrate customers from the old API to the new API endpoint. Same request format, only the URL changes.

1

Login to Admin Panel

Access Migration Portal

Log in to the Admin Panel using your admin credentials. Once logged in, navigate to the Migration section from the sidebar menu.

  • Go to https://admin.smsexpert.co.uk/
  • Enter your admin username and password
  • Click on Customers in the sidebar menu
2

Select Customer

Choose Customer to Migrate

Select a customer from the list and navigate to the Migration tab to update their API endpoint.

  • View the list of all customers
  • Click the View button on the customer you want to migrate
  • Click on the Migration tab in the customer details page
3

Migration Table

Review Migration Status

The Migration Tab shows the current migration flag status for the customer.

Migration History

Once the migration is completed, the system will display a history list showing all migration records for the customer.

4

API URL Change

New API Endpoint

After migration, customers need to update their API URL. The request format remains exactly the same - only the URL changes.

5

Customer Access URLs

New Domain Access

After migration, customers will be able to access the new domain only. Share these URLs with migrated customers:

Customer Access URLs

DASHBOARD https://dashboard.smsexpert.co.uk

Important

Once a customer is migrated, if they try to access the old URL, they will be automatically redirected to the new URL.
